# Milestone acceptance contract
Each gate requires: source SHA; exact command; exit code; machine-readable report; run timestamp; inputs/outputs and hashes when relevant. PASS is prohibited if evidence is missing.

## M1 Baseline
Canonical source identified; seven engine identities and native entry points inventoried; dependencies and previous run artifacts mapped; immutable baselines recorded; failure ledger reconciled.

## M2 Native engine readiness
For each of seven engines: isolated reproducible install, real native execution, appropriate target-conditioned reaction generation, authentic reaction records and provenance, export contract. Status separately: INSTALL / EXECUTE / SCIENTIFIC / INTEGRATED. Unsupported target chemistry must be reported as such. No fixture-only pass.

## M3 Normalization
Native outputs transformed to a common reaction schema without silently dropping reactions, atom/stoichiometric information when available, engine identity, or source metadata; regression counts and identity audit pass.

## M4 Pathway assembly
Reaction graph built from normalized records; valid connectivity, precursor closure, and cross-engine junctions independently checked; incomplete routes remain incomplete. No invented reaction bridges.

## M5 Ranking and validation
Reproducible rankings and evidence tiers; development and held-out targets separated; frozen historical scores unchanged; publish both successes and failures with confidence limits.

## M6 Product
Clean environment install, one primary Colab entry point, target-to-results run, exportable provenance/evidence, documentation and regression suite. Candidate/Mature/Certified labels preserved.
