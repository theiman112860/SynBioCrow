# SynBioCrow 2.4.28 — Correlated Feature-Block Audit

The bounded 2.4.27.1 multivariate analysis found significant but only moderate evidence-space/pathway-space distance concordance across all four development targets (approximately 0.36–0.53). PCA repeatedly showed template metadata, reaction-domain coverage, and reaction-type coverage loading together with nearly identical coefficients.

2.4.28 tests whether these three variables behave as one redundant metadata block rather than three independent evidence dimensions. It reports pairwise correlations, the fraction of routes for which all three values are identical, and each variable's association with corrected internal-anchor pathway similarity.

This is a diagnostic only. It does not alter frozen 2.4.16 ranking weights or production policy and does not access validation/evaluation truth.
