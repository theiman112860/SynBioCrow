# SynBioCrow 2.4 — Release-Certification Note

Status: **Candidate-stage scientific release**

SynBioCrow 2.4 introduces the repaired structured-reaction representation and Candidate pathway-generation architecture developed after the frozen 2.3 baseline. The release preserves a strict separation between Candidate generation, ranking, and scientific certification.

A prospectively locked two-target external evaluation was completed. The evaluation did not recover the predeclared explicit literature-pathway intermediates by exact structure. Accordingly, SynBioCrow 2.4 does not claim validated complete-pathway recovery. RetroBioCat2 backend-internal `SOLVED` statuses are reported as search outcomes only and are not treated as external validation.

No ranking policy is certified in this release (`ranking_policy = NONE`).

This negative result is retained as part of the frozen scientific record rather than tuned away after truth reveal.
